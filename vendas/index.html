O que dá para corrigir agora

EPPGG BA e DPE PB são porte M, têm inscrições abertas, edital e post no blog. Só falta a coluna Esfera no Radar para virarem campanha.

Esfera vazia
O nome do órgão não é reconhecido pela heurística do 2a. Testado no código atual: devolve vazio para os dois.
2a exige Cidade
Aguardando dados
Concurso estadual não tem Cidade, então o item nunca sai dessa situação.
Esfera = Estadual
Campanha de Conversão
